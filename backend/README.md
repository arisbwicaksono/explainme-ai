# ExplainMe AI

ExplainMe AI adalah chatbot berbasis AI yang membantu menjelaskan topik rumit menjadi sederhana dan mudah dipahami.

## Fitur
- Chat AI menggunakan Gemini API
- Memory percakapan sederhana
- UI modern dark mode
- Auto scroll chat
- LocalStorage chat history
- Clear chat feature

## Teknologi
- React + Vite
- Express.js
- Gemini API
- Tailwind CSS

## Cara Menjalankan

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
npm install
node index.js
```
